Attention

Attention lets each token decide which earlier or neighboring tokens are useful. It is a routing mechanism: queries look for matching keys, then gather values from the matched tokens.

Query, Key, Value

A token creates a query vector. Every token has a key and a value. Query-key similarity becomes an attention weight, and the output is a weighted mix of values.

\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V
