RAG

Retrieval Augmented Generation gives a language model a small, relevant set of external passages before it answers. The model still writes the answer, but the answer is grounded in retrieved context.

The Pipeline

A RAG system turns a user question into a search query, retrieves matching chunks from a knowledge base, and sends the strongest chunks into the model context. Good RAG is mostly about retrieval quality, chunk quality, ranking, and making unsupported answers visible.

Where It Fails

RAG does not make the model automatically correct. If retrieval misses the right passage, retrieves stale context, or stuffs the prompt with weak chunks, the generated answer can still be wrong. The retrieval layer gives the model evidence; it does not replace evaluation.

Useful Checks

  • Does the retrieved text actually answer the question?
  • Are chunks small enough to be specific?
  • Can the system say when evidence is missing?
  • Are citations tied to the exact retrieved passages?
