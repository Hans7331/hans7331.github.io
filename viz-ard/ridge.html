Ridge Regression

Ridge regression keeps a linear model but adds a penalty for large coefficients. It is useful when features are correlated and an unregularized fit spreads weight in unstable ways.

The Penalty

The model still tries to fit the data, but it pays an extra cost for large weights. Larger penalties shrink coefficients toward zero without selecting them out completely.

\min_\beta \sum_i (y_i-x_i^\top\beta)^2+\lambda\sum_j\beta_j^2

What Changes

  • Predictions stay linear.
  • Large coefficients become expensive.
  • Correlated features share weight more smoothly.
  • Unlike lasso, ridge usually keeps every feature active.
