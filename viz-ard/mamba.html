Mamba / State Space Models

State-space sequence models keep a compact hidden state and scan through tokens. Instead of comparing every token to every other token, the model updates memory step by step.

The Recurrence

A state-space model carries a state forward. Mamba-style models make parts of that update depend on the current token, so the model can selectively remember or forget information as it scans.

h_t=A(x_t)h_{t-1}+B(x_t)x_t,\quad y_t=C(x_t)h_t

State Scan

Each card is one scan step. The state is carried forward, decayed by retention, and updated by the token input.

Attention vs SSM

  • Attention reads across token pairs.
  • State-space models scan with a compact state.
  • Mamba adds input-dependent selection to that scan.
  • The design is attractive for long sequences.
