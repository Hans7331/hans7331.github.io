LLM Basics

A large language model repeatedly predicts the next token. The generated text looks like prose, but the primitive operation is a probability distribution over tokens at every step.

Next Token Prediction

The model reads a context window and returns scores called logits. Softmax turns those scores into probabilities, and decoding chooses one token from that distribution.

P(t_{n+1}\mid t_1,\ldots,t_n)=\mathrm{softmax}(z)
