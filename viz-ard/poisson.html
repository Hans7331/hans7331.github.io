Poisson Regression

Poisson regression is built for counts. Instead of predicting a value directly, it predicts a positive event rate, then treats the observed count as a draw from that rate.

The Model

The log link is the central move. A straight line can go negative, but a count rate cannot. By modeling the log of lambda as linear and exponentiating it, the model keeps the expected count positive for every x.

Y_i \sim \mathrm{Poisson}(\lambda_i), \quad \log(\lambda_i)=\beta_0+\beta_1x_i

Reading The Chart

The dots are sampled counts. The curve is the expected count from the model. Because the line is exponentiated, a constant slope on the log scale becomes multiplicative growth or decay on the count scale.

The rate ratio is the easiest interpretation: if the rate ratio is 1.20, then one more unit of x multiplies the expected count by 1.20.

Use It When

  • The target is a count: clicks, defects, arrivals, incidents.
  • Counts are non-negative integers.
  • Exposure matters, such as time watched or distance driven.
